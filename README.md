# UltraAutopeli

Selaimessa toimiva 3D-autopeli, jossa autoa ohjataan kallistamalla puhelinta kuin rattia.

▶️ **Pelaa: https://mikri.github.io/ultraautopeli/**

## Asenna sovellukseksi

Peli on PWA, joten sen voi lisätä puhelimen kotinäytölle omalla kuvakkeellaan, ja se avautuu koko näytölle:

- **iPhone (Safari):** Jaa-painike → *Lisää Koti-valikkoon*.
- **Android (Chrome):** valikko ⋮ → *Asenna sovellus* (tai *Lisää aloitusnäytölle*).

## Pelissä

- Kolme autoa: perheauto (rauhallinen), pakettiauto (hidas) ja urheiluauto (nopea).
- Kisa: aja reitti tarkistuspisteiden kautta kolmea kilpailijaa vastaan. Paras aika tallentuu autokohtaisesti. Kisassa ei tule sakkoja.

- Kaupunki, jossa on liikennevaloja ja nopeusrajoituksia (pääkaduilla 60 km/h, muilla 40 km/h).
- Sakko tulee, jos ajat päin punaisia tai ajat yli 10 km/h ylinopeutta yli 2 sekunnin ajan. Jokainen sakko on 60 €.
- Kaduilla ajaa muita autoja, jotka pysähtyvät punaisiin valoihin ja kääntyilevät risteyksissä.
- Moottoritie: loputon moottoritie metsän halki, liikennettä molempiin suuntiin, rajoitus 120 km/h.
- Nopeudenrajoitin (Rajoitin-nappi tai L-näppäin): pois, auto (noudattaa voimassa olevaa rajoitusta) tai 40–120 km/h.
- Peli toimii vain vaakasuunnassa.

## Ohjaus

- **Puhelin:** käännä puhelin vaakaan ja paina "Aja!". Pidä puhelinta vaakatasossa näyttö ylöspäin ja kallista vasemmalle tai oikealle. Jarru on näytön vasemmassa ja kaasu oikeassa reunassa. Kalibroi-nappi asettaa nykyisen asennon suoraksi.
- **Tietokone:** välilyönti = kaasu, Shift = jarru (pysähdyksissä peruutus), nuolet tai A/D = käännä, R = alkuun. Näytön rattia voi myös vetää hiirellä.
